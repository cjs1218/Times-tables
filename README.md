# Times-tables

**Times Table Stars**: a dyslexia-friendly times tables practice app for Year 3 and 4 children (tables up to 12 × 12).

Open `index.html` in a browser, or turn on GitHub Pages for this repo to play it online. Progress is saved on each device.

## Features
- Choose which tables to practise (grown-up or child); each table has its own colour
- Calm, dyslexia-friendly design: tinted page colours, clear fonts, one question at a time, read-aloud
- No timer by default; optional 12-second or 6-second (Year 4 Multiplication Tables Check) mode
- New facts start as multiple choice, then move to typing on a big number pad
- Dot pictures, friend-fact hints, rhymes and picture stories for the hardest facts
- Pairs game, Teach the Cat (spot the cat's mistakes) and a fact of the week
- Stars build a tree house, then a castle, then a rocket
- 12 × 12 progress grid and a grown-up summary that can be copied for school
